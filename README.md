## 功能

- **商品主图**：完整外观、核心细节、使用场景及多角度展示。
- **详情页**：标题、卖点说明、结构标注、规格与场景模块。
- **实拍优化**：结合参考图整理修图方向，改善曝光、白平衡、背景与清晰度，保持产品比例。
- **营销素材**：广告、社媒、Banner、包装与创意视觉。
- **多图一致性**：固定设计语言，安排不同视角、景别与浏览节奏。
- **事实约束**：区分用户提供的信息、照片可见特征和待确认参数。

整套商品图默认规划 **5 张主图 + 7–9 张详情图**；用户指定的数量、尺寸和范围优先。也可以只生成提示词、单张图片或修改指定页面。
## 运行方式

| 方式 | 所需条件 | 可交付内容 |
| --- | --- | --- |
| Brief / Prompt | 能读取 Skill 的 AI 代理 | 视觉简报、图片清单、风格锁、提示词与文案 |
| 宿主内置生图 | 当前会话具备图片生成工具 | 上述内容与生成图片 |
| apiz CLI | Python 3.9+、apiz CLI 及可用账户 | 通过脚本提交任务并下载图片 |
| 可编辑设计文件 | 宿主另有设计编辑工具及所需字体 | 按实际工具能力制作和验证源文件 |

这是给 AI 代理使用的 Skill，不是独立桌面软件。`scripts/generate_image.py` 是可选的出图辅助脚本，仅使用 Python 标准库。

目录与调用方式参考 [Codex 官方说明](https://learn.chatgpt.com/docs/build-skills) 和 [Claude Code 官方说明](https://code.claude.com/docs/en/skills)。使用其他宿主或旧版客户端时，按其实际技能目录安装，避免重复安装同名技能。

## 快速开始

在支持的代理中调用 Skill，并附上产品图：

```text
用 ecom-details-image 为这款产品制作 5 张主图和 8 张详情图。

产品：便携咖啡杯
受众：日常通勤人群
参考：我提供的产品图和配色参考
风格：简洁、有少量复古感，主色由参考图确定
要求：产品保持真实比例，包含完整展示和局部特写。
文案：只使用我已确认的参数，其他信息先省略。
尺寸：主图 1:1，详情图 2:3
交付：PNG、图片清单与预览
保存位置：我指定的项目文件夹
```

只需要提示词时，补充“本次仅输出简报与提示词”。修改已确认的方案时，明确页码和保留项。

更多输入结构见 [商品简报示例](examples/product-brief.md)。

## 可选：通过 apiz CLI 出图
当前会话已有可用生图工具时，按宿主工具工作流执行，无需配置此脚本。选择 apiz 通道时，先按 [apiz 官方说明](https://apiz.ai/) 安装 CLI，再检查并登录：

代理整理整套商品图时，建议使用：

```text
generated-images/product-name/
├── brief.md
├── image-pack-plan.json
├── prompts/
├── hero/                  # 主图
├── detail/                # 详情图
├── source/                # 仅在已制作源文件时提供
└── preview/               # 总览或浏览预览
```

这是交付约定，不是脚本自动创建的全部目录。脚本默认下载为 `image-时间戳-序号.扩展名`；主图与详情的编号、重命名和归档由代理整理。

## 可编辑 PSD
